# Лабораторная работа №1. Введение в машинное обучение и подготовка данных

## 1. Выбранный датасет

**Bank Marketing Dataset** (`bank.csv`)  — данные телефонной маркетинговой кампании банковского учреждения. Каждая строка — один клиент, с которым связался колл-центр, предлагая открыть срочный депозит.

Источник: [Bank Marketing Dataset на Kaggle](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)

## 2. Бизнес-задача

Предсказать, откроет ли клиент депозит, по данным о нём. Это поможет банку звонить не всем подряд, а только тем, кто скорее всего согласится. Так мы сэкономим деньги на пустых звонках и сделаем работу колл-центра эффективнее.

## 3. Основные выводы

1. Выполнена загрузка датасета, проверка структуры и типов данных. Удалены неподходящие признаки ('poutcome', 'contact').

2. По графику видно, что медианы и основные возрастные диапозоны в группах "yes" и "no" практический совпадают. Только среди согласившихся немного больше пожилых людей.


3. Отделили целевую переменную y. Остальные признаки перевели из текста в нули и единицы (get_dummies), убрали дублирование.

4. Подготовили данные для модели. Исходный набор данных был разделен на обучающую (80%) и тестовую (20%) выборки. Далее числовые признаки отмасштабировали через StandardScaler, чтобы большие числа вроде баланса не перебивали маленькие вроде возраста.

5. Общая точность модели (Accuracy) на тестовых данных составила 84.10%. Этого достаточно, чтобы операторы могли эффективно приоритезировать базу и звонить в первую очередь тем, кто с высокой вероятностью откроет депозит.
