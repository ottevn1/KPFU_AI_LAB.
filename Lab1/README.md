# Лабораторная работа №1. Введение в машинное обучение и подготовка данных

## 1. Выбранный датасет

**Bank Marketing Dataset** (`bank.csv`)  — данные телефонной маркетинговой кампании банковского учреждения. Каждая строка — один клиент, с которым связался колл-центр, предлагая открыть срочный депозит.

Источник: [Bank Marketing Dataset на Kaggle](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)

## 2. Бизнес-задача

Предсказать, откроет ли клиент депозит, по данным о нём. Это поможет банку звонить не всем подряд, а только тем, кто скорее всего согласится. Так мы сэкономим деньги на пустых звонках и сделаем работу колл-центра эффективнее.

## 3. Основные выводы

1. Возраст влияет на решение. Клиенты старшего возраста чаще соглашаются на депозит.

2. Образование связано с балансом.Клиенты с высшим образованием имеют наибольший средний баланс на счёте.

3. Мы удалили столбцы "poutcome" (результат прошлых контактов с банком) и "contact" (способ связи с клиентом), так как для нашего прогноза они не нужны 

3. Для корректной работы с несбалансированными данными применён параметр class_weight="balanced".

4. Общая точность модели (Accuracy) на тестовых данных составила 84.19%. Этого достаточно, чтобы операторы могли эффективно приоритезировать базу и звонить в первую очередь тем, кто с высокой вероятностью откроет депозит.
